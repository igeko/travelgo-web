Note per gli agenti che svilupperanno i componenti

Tassonomia dei file

  • UI di prodotto (colonna sinistra): pagine vicine a quello che sarà il prodotto. Sono la fonte di verità del visual design.
  • Esplorazioni / wireframe (colonna destra): solo riferimento di processo. Non implementare da questi.
  • Gerarchia visiva: le card annidate (con bordo arancio tratteggiato) sono sub-componenti che vivono dentro la pagina genitore.

Stile e tokens

  • Un unico file styles.css contiene tutte le regole condivise (variabili, tipografia, layout, componenti). Da usare in ogni pagina prototipo.
  • Variabili principali: --bg #f1efe8, --surface #ffffff, --ink #0d2c3d, --orange #f47b3a, --orange-deep #a84818.
  • Radius: --radius-sm 8px, --radius-md 12px, --radius-lg 14px, --radius-pill 999px.
  • Icone: Tabler webfont via CDN. Per icone problematiche (pencil, x) usare unicode ✎ / × o SVG inline.

Mapping con il codice React

  • Day-by-Day → src/pages/DayByDay.jsx
  • Day edit / inline forms → src/components/InlineEditDay.jsx, InlineActivityForm.jsx, ActivitySectionEditor.jsx
  • Address autocomplete → src/components/AddressAutocomplete.jsx + lib/geocoding.js
  • Budget → src/components/sidebar/BudgetEditor.jsx, BudgetView.jsx + lib/exchange.js
  • Edit mode globale → src/lib/EditModeProvider.jsx

Pattern stabili da implementare

  • Stato attività: 3 stati visivi della riga — default, now (sfondo bianco + barra arancio sinistra + tag ORA), selected (sfondo bianco senza barra né tag).
  • Componente "Quando": barra segmentata 4 fasce (Mattina/Pomeriggio/Sera/Notte) con range orario inline; click apre picker due colonne (ore della fascia, minuti step 5); l'orario selezionato compare DENTRO la cella attiva al posto del range; "azzera orario" torna a sola fascia.
  • Edit form accordion: matita pencil su ogni blocco apre form ancorato (con triangolino di aggancio) che sostituisce/affianca la view. Continuità grafica tra hero + form + lodging quando si apre l'edit intestazione/alloggio.
  • Soft input: campo pill (border-radius pill, padding 8/18, background #fafaf6, label ghost in alto-sinistra che compare al focus, focus ring arancio).
  • Campi opzionali: indirizzo, budget e link sono nascosti di default e si aprono via link "+ Aggiungi …" che apre il componente sotto. Bottone × esterno al componente per rimuovere.
  • Pill budget: input + simbolo valuta prefisso + pill valuta ink scura cliccabile (cycle JPY↔EUR) + conversione live. Una sola riga.
  • Pill stato attività: cycle al click tra null, todo (rosso), booked (giallo), paid (verde).

Cose da NON portare in produzione

  • I file in tmp/ e wireframe/ servono solo a leggere la storia delle decisioni.
  • Le matite renderizzate come testo Unicode (✎, ×) sono un workaround per il glyph mancante nel webfont — in React usare icone Tabler SVG (lucide-react o @tabler/icons-react) direttamente.
