Persistito vs effimero

Cachesystem + catalogo tools + history — prefisso stabile, cresce solo in coda.
Effimeroil context per-turno (giorno selezionato, trip-context) — dopo la history, mai persistito.
DBgo_messages: user / assistant / tool. historyAsLlm li rilegge; displayTurns re-idrata le card.
Round-tripla conferma scrive assistant(tool_call)+tool(result): il modello vede l'esecuzione → non ripropone.
