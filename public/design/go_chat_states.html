1Closed · mini-card resume

Quando la chat è chiusa e c'è già stata almeno una conversazione, mostra un mini-card flottante in basso a destra con l'ultima cosa detta da Go. Click → riapre il panel.

2Opening · primo turno · Go sta scrivendo

Al click di "Ask me" il panel si apre e Go fa un saluto proattivo. La frase si compone token-by-token (streaming). Avatar piccolo in basso a sinistra del messaggio anima (wobble + halo + entrata fade-scale). Sopra il messaggio puntini pulsanti. Caret arancione a fine frase.

Animazioni
  • goEnter 0.25s · fade + scale 0.85→1 (avatar appare)
  • goWobble 1.6s infinite · oscillazione ±3deg / ±2px
  • goPulseHalo 2s infinite · halo arancione
  • goTyping 1.4s infinite · 3 puntini (delay 0.2s, 0.4s)
  • goCaret 1s steps(1) · cursore blink
Markup chiave
  • .ai-live wrapper con padding-left 38px (spazio avatar)
  • .ai-live .av position absolute bottom-left
  • .ai-live .ai-msg border-left 2px arancione, padding-left 12px
  • Token chiave evidenziati con <strong> · bg arancio-light + padding 4px + radius 3px (font sans, niente più italic)
Input
  • Durante streaming l'input è disabled (l'utente non può rispondere finché Go non finisce)
3Messaggio completato · idle "ti ascolto"

Quando Go ha finito il turno: avatar e caret accanto al messaggio scompaiono, border-left arancione idem. Subito sotto appare l'idle "ti ascolto…": avatar fermo + halo lento + eyebrow Go + hint serif. Quick-replies sotto. Input attivo.

Quick replies

  • Click su un chip → invia come user message (vedi stato 4)
4User reply · Go riprende a scrivere

Chip-riferimento nella user bubble
  • .user-msg .ref · pill 10px, bg arancio 20%, color --orange-deep
  • Inseriti automaticamente dal frontend dalle card selezionate
  • Inviati a OpenAI come parte del prompt + conservati per il tool-call
Pulizia selezione
  • Dopo l'invio, le selezioni si azzerano (counter torna a 0, card tornano normali)
  • I nuovi risultati arrivano senza selezione preimpostata
Riferimento nel messaggio Go
  • Go cita i riferimenti con <strong> nel suo messaggio successivo
  • Pattern: "Ho tenuto X come riferimento. [azione]…"
