Atomi base del form system. Niente bordi, niente wrapper, niente bg dei campi: il valore è inline, la riga è la grammatica del passaporto. Caret + label arancio sono gli unici segnali di attività. Il popover dell'autocomplete è flottante, in posizione assoluta sotto il campo: non prende spazio verticale, non spinge giù il layout.

Autocomplete · popover flottante

Position absolute

Il popover dei risultati è flottante in position: absolute: appare sotto il campo input ma non occupa spazio verticale. Le righe sottostanti (se ci sono, es. in una card multi-campo) restano dove sono. La superficie del popover ha shadow morbida e radius 10px. Indent 24px da sinistra per allineare col valore (dopo icona + gap).

Spec di implementazione — React + Tailwind

Due componenti separati. Path proposti: components/ui/Input.tsx e components/ui/Autocomplete.tsx. Entrambi controlled.

Input · props

PropTipoDescrizione
value string Valore corrente.
placeholder string? Mostrato quando value è vuoto. Italic faint.
label string? Eyebrow uppercase mini. Omettibile (variante B/D).
icon ReactNode? Tabler icon 14px. Omettibile (variante C/D).
active boolean Campo in focus. Mostra caret e tinge label arancio.
disabled boolean Opacity ridotta, cursor not-allowed.
error boolean Valore arancio-deep.
errorMessage string? Micro-frase sotto la riga, italic. Può contenere link inline.
onChange (value: string) => void Cambio valore. Per behavior controlled.
onCommit (value: string) => void Enter, blur. Salva il valore.
onCancel () => void Esc. Ripristina valore precedente.

Autocomplete · props (estende Input)

PropTipoDescrizione
options Option[] Lista risultati. Ogni opzione: { id, name, tag?, icon? }.
loading boolean Mostra spinner inline a destra del caret, nasconde il popover.
highlightMatch boolean Default true. Wrappa porzione matched in <em>.
onSelect (option) => void Click su opzione o Enter su quella in keyboard focus.
emptyState ReactNode? Mostrato quando options vuoto. Default: micro-frase con fallback a Go.
onAskGo () => void Click su "chiedi a Go" nell'empty state.

Comportamenti runtime

Posizionamento popover position: absolute; top: calc(100% + 4px); left: 24px. Indent 24px = icona (14px) + gap (10px), così è allineato col valore.
Z-index 50. Sopra le righe sottostanti, sotto modali (suggested: --z-index-overlay = 40 per la card, 50 per il popover).
Overflow del parent Il container del popover deve avere overflow: visible. Se il parent ha overflow: hidden (es. card con bordi rounded), il popover viene clippato. Soluzione: rendi visibile, oppure usa portal.
Animazione entrata 0.18s cubic-bezier(0.34, 1.56, 0.64, 1), transform-origin top-left. Opacity 0 → 1, translateY -4 → 0.
Keyboard nav ↑↓ scorri opzioni, ↵ scegli (in keyboard focus), Esc chiudi.
Hover/focus background: rgba(244,123,58,0.08). Niente border-left arancio: stato espresso solo dal bg + colore icona + colore tag.
Debounce 250ms tra typing e fetch dei risultati. Il loading spinner appare dopo 150ms se la fetch non ha ancora risposto (evita flicker).
Match highlight La porzione della query che matcha è wrappata in <em> con bg arancio-soft 18% + color primary-deep + radius 2px.
